## Раздел 1. Создание пользователя

**Цель:** создать пользователя `user1` с UID 1234, входящего в группу `students`, с обязательной сменой пароля каждые 3 месяца.

**Выполненные команды:**

```bash
# Создание пользователя с заданным UID и группой
sudo useradd -u 1234 -g students user1

# Установка пароля
sudo passwd user1

# Настройка срока действия пароля — 90 дней
sudo chage -M 90 user1

# Проверка результата
id user1
sudo grep user1 /etc/shadow
```

## Раздел 2. Мониторинг файлов и процессов

**Цель:** Найти в системе все файлы с установленным битом set-UID; Найти в системе все процессы, у которых эффективный UID равен 0, а реальный UID относится к обычным пользователям.

**Выполненные команды:**

```bash
# Поиск файлов с установленным битом set-UID
sudo find / -perm -4000 -fprintf /root/suid.txt '%#m %u %p\n'


# Поиск процессов, у которых эффективный UID = 0, а реальный UID ≥ 1000
sudo ps -eo pid,ruid,euid,comm | awk '$2 >= 1000 && $3 == 0' > procout.txt
cat procout.txt
```
## Раздел 3. Изучение механизма set-UID

**Цель:** Выберать существующую утилиту, с помощью механизма set-UID обеспечить выполнение утилитой привилегированной операции.

**Утилита:** cat.

**Привилегированная операция:** чтение файла /etc/shadow, доступного только root.

**Выполненные команды:**

```bash

# Копирование утилиты в домашний каталог
cp /usr/bin/cat ~/cat1/

# Смена привелегий
sudo chown root:root ~/cat1/cat
sudo chmod u+s ~/cat1/cat

# Выполнение привилегированной операции
~/cat1/cat /etc/shadow
```
## Раздел 4. Изучение механизма привилегий

**Цель:** Выбрать существующую утилиту, c помощью механизма привилегий обеспечить выполнение утилитой привилегированной операции.

**Утилита:** chown.

**Привилегированная операция:** смена владельца файла test.

**Выполненные команды:**

```bash
# Копирование утилиты в домашний каталог
cp /usr/bin/chown ~/chown1/

# Смена привелегий
sudo setcap "cap_chown=ep" chown

# Выполнение привилегированной операции
~/chown1/chown root ~/chown1/test

```
## Раздел 5. Изучение механизма sudo

**Цель:** С помощью механизма sudo разрешить пользователю user1 устанавливать (изменять) системное время.

**Выполненные команды:**

```bash
# Редактирование конфигурационного файла /etc/sudoers
sudo visudo

# Выдача прав на выполнение команды
user1   ALL=(root) /usr/bin/date

# Смена времени
sudo -u user1 sudo date --set="Sat Sep 30 18:20:20 EEST 2026"

```
